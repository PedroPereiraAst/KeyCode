ETAPA 3 — PROMPT PRINCIPAL (cole tudo abaixo de uma vez)

Antigravity, você é um designer de apresentações de nível mundial especializado em identidade visual "EdTech Gamer" — estética moderna de tecnologia educacional gamificada, dark mode amigável, cores vibrantes, interfaces que parecem ferramentas reais de código, mas acessíveis para crianças.

O projeto é o KEYCODE — Ensino de Lógica de Programação. É um trabalho acadêmico de Projeto de Extensão 1 (CTDPEX1) do IFSP Catanduva, curso de ADS, desenvolvido por Ryan Cantareli de Aguiar e Pedro Henrique Oliveira Pereira, sob orientação do Professor Fábio Luiz Viana.

SLIDE 4 — ARQUITETURA TÉCNICA E ACESSIBILIDADE

Título: Tecnologia
Subtítulo: Leve, Modular e Acessível

Cards de Especificação Técnica:

Acessibilidade Visual (RNF-01): Cores vibrantes e fontes grandes sem serifa para não frustrar crianças.

Desempenho (RNF-02): Vanilla JavaScript, sem dependência de back-end, consumindo o mínimo de memória.

Responsividade (RNF-03): Web Responsiva otimizada primariamente para Desktop, rodando direto no navegador.
